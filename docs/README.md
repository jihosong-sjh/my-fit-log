## 공통 용어와 범위

- **Phase**: 구현 체크리스트의 `0~29`만 사용한다. 다른 문서의 일반 장 번호와 구분한다.
- **MVP**: P0 핵심 기능과 P1 완성도 기능을 모두 포함한다. P0만 구현한 상태는 중간 시연 버전이다.
- **후속 릴리스(P2)**: MVP 이후 기능이다. 기존 PRD의 확장 버전 명칭인 “Phase 2”를 대체한다.
- **개발 완료**: Phase 22까지 통과. 코드·자동 테스트·로컬 운영 이미지·배포/복구 준비가 완료된 상태다.
- **운영 준비 완료**: Phase 23~28까지 실제 장비에서 통과. 외부 접속과 복구를 확인한 상태다.
- **MVP 완료**: Phase 29에서 기능·운영 증거를 검토하고 1~2주 실사용 검증까지 마친 상태다.

## 작업 경계

| 구간 | 범위 | 담당 |
|---|---|---|
| Phase 0~18 | 기능 구현, 보안·접근성, API·통합·E2E·로컬 성능 검증 | 개발 담당(에이전트 수행 가능) |
| Phase 19~22 | 운영 이미지, 환경변수 계약, 배포·백업·복구 스크립트와 격리 환경 검증 | 개발 담당(에이전트 수행 가능) |
| Phase 23~25 | 실제 MacBook, 운영 환경변수, Tailscale, 첫 배포, 운영 백업 | 운영자와 개발 담당 공동 |
| Phase 26~29 | 덮개·재부팅·장애·실기기·실사용 검증 | 운영자 중심, 에이전트는 진단·수정 지원 |

운영 환경변수·스크립트 작성 자체가 수작업 전용인 것은 아니다. 계정 인증, 장비 접근 권한, 실제 주소·저장 경로 확정, 물리 조작, 외부 기기 확인이 운영자 참여 지점이다. 로컬 모사 테스트를 실장비 검증 완료로 간주하지 않는다.

## 이번 정리의 결정

- Settings와 목표 설정을 Dashboard보다 먼저 구현한다.
- 원래 요구에 있던 유산소, 운동·음식 즐겨찾기, 식단 프리셋, 운동 루틴을 MVP에 포함한다.
- 기본 운동 seed는 웨이트 13종 + 러닝·줄넘기 등 유산소 7종이다. 공통 카탈로그에서 유형을 구분하고 웨이트는 세트·중량·횟수, 유산소는 시간·거리 또는 줄넘기 횟수를 기록한다.
- 세션 저장, 사용자 설정, 유산소, 즐겨찾기, 프리셋의 누락 모델을 보완한다.
- 걸음수·물·독립 메모·Streak·PR/1RM·추가 신체 치수·사진·PWA·범용 오프라인 동기화는 후속 릴리스로 명시한다. 운동 작성 중 Draft 저장·복구·재시도는 MVP에 포함한다.
- 개인 계정 생성은 서버 관리 명령으로 제공한다. 공개 회원가입·이메일 인증·비밀번호 재설정 메일은 후속 범위다.
- 날짜 기준은 MVP에서 `Asia/Seoul`, 시간은 UTC 저장, 주간 집계는 월요일 시작으로 통일한다.
- 기존 상세 Phase 0~36의 변경 대응표는 구현 체크리스트 부록에 보존한다.
